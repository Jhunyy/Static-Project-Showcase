Project Idea

Understanding our approach to combating Smishing attacks

Keyword-Based Scam Link (Smishing) Detection in Text Messages

2025 Research Project Mobile Security Research Group

Problem Statement

As SMS usage continues to grow globally, so do smishing attacks. These fraudulent text messages trick individuals into revealing confidential information or clicking malicious links. Many users, especially those less familiar with digital threats, struggle to identify deceptive messages, putting personal data, finances, and privacy at significant risk.

Current solutions often rely on blacklisting known malicious URLs, but this approach fails to detect new or evolving threats. There's a critical need for a proactive, intelligent system that can identify potential smishing attempts in real-time.

Project Objective

Our project aims to develop a mobile-based detection system that automatically scans text messages, identifies suspicious keywords or URLs, and alerts users before they engage with potentially harmful content.

The system will utilize a database-driven keyword detection method to identify potential smishing messages in real time. By matching text content against a regularly updated list of known scam-related keywords and URLs, it ensures efficient and reliable protection without affecting user privacy or device performance.

Key Features

  • Intelligent Scanning

    Scans incoming SMS messages for known scam keywords and URLs using advanced pattern recognition

  • Real-time Alerts

    Provides immediate warnings when suspicious content is detected, before users click on links

  • Lightweight Algorithm

    Utilizes a keyword-based approach for fast, efficient detection that doesn't drain device resources

  • Comprehensive Protection

    Helps users stay safe from phishing, smishing, and various fraud attempts targeting mobile users

  • User Education

    Promotes awareness and safer communication practices through educational notifications
